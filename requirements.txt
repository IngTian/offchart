# Two runtime dependencies, and that is deliberate.
#
# The store is SQLite, which is in the standard library. HTTP is urllib, also standard
# library -- these are public JSON and CSV endpoints, none of which needs `requests`.
# The display layer is Grafana, which is a container and not a Python package. So what
# is left is the dataframe library the statistics are written against, and the runner
# for the tests that prove them.
#
# What used to be here, and why it is gone:
#   pyarrow==25.*   pinned for byte-reproducible parquet, so an unchanged day produced
#                   an identical file and an empty git diff. There is no parquet now;
#                   the store is one gitignored SQLite file, and durability comes from
#                   the committed CSVs in data/snapshots/ instead.
#   streamlit,      the hand-maintained board. Replaced by Grafana reading SQL, which
#   plotly          is why this repo now owns data and preprocessing only.
pandas>=3.0,<4

# Not optional here. These tests pin three corrections this repo has already had to
# make once (the open-interest residual is rounding, not an unpublished spread;
# sum(net) is not exact; the concentration columns divide by the side total), and they
# are the enforcement mechanism for the two rules that matter -- causal ranks only,
# and no committed artefact for a source we may not redistribute.
pytest>=8.0
