# offchart

**The data TradingView doesn't carry, in a database Grafana can read.**

Positioning, fund flows and survey expectations are free and reproducible from primary
sources. What's missing isn't the data, it's the plumbing: a place they all land with the
same shape, the same cadence handling, and the same statistics applied honestly. That's
all this repo is.

It owns **data and preprocessing**. It owns no charting code. Rendering is Grafana,
provisioned from committed JSON — because a hand-maintained chart layer cost more than
the data ever did, and Grafana already does crosshairs, zoom, fullscreen and export
better than a bespoke one will.

## Is this you?

**Yes, if** you want the whole CFTC cross-section rather than a curated handful, you'd
rather write SQL against 4.8 million rows than click through someone's dashboard, and
you care that a percentile was computed without look-ahead. The base-rate question —
"how unusual is this reading, against this market's own history" — is what the repo is
built around, and answering it honestly is most of the code.

**Probably not, if** you want a chart of SPX with an indicator on it, you want
intraday anything, or you want a signal. Nothing here tests a relationship between
positioning and price; the board shows them side by side and deliberately stops there.
See [what the data does and does not say](docs/data-notes.md) before reading a number
off a panel.

**It runs entirely on your machine.** No account, no key, no server, no telemetry. One
SQLite file you can delete.

## This repository contains no data

It is a fetcher and a Grafana wiring, nothing else. **No dataset from any source here is
stored in this repository, now or in its history.** You run `make pull` and the data
lands in `data/offchart.sqlite` on your own machine, gitignored and never committed — not
as a convention but as something the test suite asserts, by asking git directly, over
every path a `--db` run could write to.

The code is MIT; the data is not ours to license and we do not host, mirror or
redistribute any of it. Each source carries the upstream's own terms and required
attribution verbatim, and a source whose terms forbid mirroring is marked
`redistributable=False`.

That framing settles redistribution completely and settles nothing about terms that
restrict *creating* a local database — which is why FINRA's margin debt and short
interest are **absent** rather than fetched, and why the Fed's Z.1 was tried as a
substitute and rejected. A source is not added here because its data would be useful.
The full position, with the clauses quoted, is in
[docs/licensing.md](docs/licensing.md).

## The three boards

**CFTC positioning** — pick a report family, a market and a cohort group; read that
group's position as a share of open interest against its own history, with long, short,
gross and directional purity beside the net, the underlying price above and open
interest below.

**ETF flows** — creation and redemption in dollars for 23 funds across six index
families, leveraged and unleveraged together, plus the mechanical rebalancing a 1% index
move forces on the leveraged ones. A net of zero and a large hedged book are different
animals, and so are discretionary money and money that must trade whatever it thinks.

**Inflation expectations (UMich)** — median expected price change over the next year and
the next 5–10 years, each ranked within its own regime, plus the sentiment index and its
two components.

They are **separate dashboards on purpose.** A monthly household survey, daily fund
flows and weekly futures positioning share no market, no cadence and no denominator, and
putting them on one canvas invites reading a relationship that nothing here tests.

## Install

Needs [uv](https://docs.astral.sh/uv/) and Docker, for Grafana.

```
git clone https://github.com/IngTian/offchart.git
cd offchart

make venv        # .venv, built by uv. No activation needed afterwards.
```

Python itself is not a prerequisite — `make venv` fetches a standalone interpreter when
the system has none. Two dependencies: pandas, and pytest for the suite.

## Get the data

```
make backfill    # full history: ~5 min, ~900 MB fetched
make grafana     # start Grafana -> http://localhost:3000
```

Boards appear under the **Offchart** folder. If you'd rather use a Grafana you already
run, see [docs/grafana.md](docs/grafana.md).

## Keep it current

```
make pull
```

That's the only command you need from then on. It's deliberately one command for a
two-step job — fetch, then rebuild the derived tables — because forgetting the second
step leaves the charts showing last week's numbers with no error anywhere.

**Nothing schedules it.** There is no cron here; the data is as fresh as the last time
you ran it. `make status` says what you have and how stale it is, which matters because
a chart drawn from a database that stopped updating three weeks ago looks exactly like a
chart drawn from a fresh one.

```
  flows
    gld_flows                  5,567  2026-11-06       2d  Daily, the file is overwritten…
    proshares_flows           77,027  2026-11-06       2d  Daily, overnight T+1
    smh_flows                  4,106  2026-11-06       2d  Daily, through the previous close…
    spy_flows                  5,773  2026-11-05       3d  Daily, the file is overwritten…

  board_flows                 92,473  2026-11-06       2d  serving
```

CFTC publishes Friday 15:30 ET for positions as of Tuesday. The pull is incremental and
its window **overlaps** what you already have on purpose, because CFTC revises
already-published weeks and the key is a real primary key, so a revision overwrites
rather than duplicating. Run it as often or as rarely as you like.

`make help` lists the rest. `make backfill` after changing a field map or widening the
market universe.

## Your data stays on your machine

`data/offchart.sqlite` is yours. It is gitignored at every path a `--db` run can write
to, nothing in this repo phones anywhere except the publishers you fetch from, and
Grafana runs locally with no volume of its own — delete the container and nothing is
lost.

Recovery is `rm data/offchart.sqlite && make backfill`. Every source serves its own
history back, so nothing here is kept only by this repo.
